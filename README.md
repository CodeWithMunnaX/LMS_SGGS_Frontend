# LearnPulse LMS — React Frontend

Modern React 18 + Tailwind CSS frontend for the LearnPulse Learning Management System.

---

## 🌟 Features
- **Modern Dark UI**: Glassmorphic styling, responsive layout, and glowing components.
- **Interactive Classroom**: Custom video player with speed controls, syllabus sidebar, note-taking, and quizzes.
- **Verified Certificates**: Confetti celebration and official credential PDF/print layout.
- **Course Studio**: 4-Step course creation wizard with Cloudinary video/thumbnail uploader.
- **Role Portals**: Student dashboard, instructor analytics studio, and admin panel.
- **1-Click Demo Persona Switcher**: Instant role testing in the top navigation bar.

---

## 🚀 Setup Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   # App runs on http://localhost:5173
   ```

3. **Production Build**:
   ```bash
   npm run build
   ```
